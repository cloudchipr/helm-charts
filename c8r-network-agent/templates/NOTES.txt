  $(kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/component=agent -o jsonpath='{.items[0].metadata.name}') \

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

If agents aren't collecting data:
  1. Verify conntrack accounting: cat /proc/sys/net/netfilter/nf_conntrack_acct
  2. Check init container logs for errors
  3. Ensure NET_ADMIN capability is allowed

If server isn't receiving data:
  1. Check gRPC connectivity between agent and server
  2. Verify service DNS resolution
  3. Check firewall rules for port {{ .Values.service.port }}
